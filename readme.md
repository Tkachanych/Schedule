# Школьное расписание с подсветкой пересечений

Простая локальная веб-страница для просмотра расписания занятий на текущую и следующую неделю.

Страница показывает занятия, подсвечивает конфликты по времени, позволяет добавлять/изменять/удалять занятия, выгружать и загружать конфиг.

Проект сделан без сервера, без сборки и без установки. Это один HTML-файл и, при желании, рядом лежащий файл конфига.

---

## Возможности

- Просмотр расписания на:
  - текущую неделю;
  - следующую неделю.
- Подсветка пересечений по времени.
- Разные цвета типов занятий:
  - Персональное;
  - С классом.
- Быстрое добавление занятий:
  - кнопка + на каждом дне недели;
  - дублирование существующего занятия;
  - режим "добавлять подряд".
- Настройка звонков как шаблонов времени.
- Экспорт конфига:
  - schedule-config.js — для автоподхвата при открытии страницы;
  - schedule-config.json — для резервной копии или ручного просмотра.
- Импорт конфига:
  - .json;
  - .js.
- Хранение данных в браузере через localStorage.

## Быстрый старт

### 1. Сохрани файл страницы

Сохрани HTML-код как:

  schedule.html

### 2. Создай файл конфига

Рядом с schedule.html создай файл:

  schedule-config.js

Минимальное содержимое:

  window.SCHEDULE_CONFIG = {
    "version": 1,
    "exportedAt": "initial",
    "bells": [],
    "lessons": []
  };

### 3. Открой страницу

Открой schedule.html в браузере двойным кликом.

Если файла schedule-config.js нет, страница всё равно будет работать, но данные будут храниться только в браузере.

## Как пользоваться

### Добавление занятия

Заполни поля:

- название занятия;
- день недели;
- тип занятия:
  - Персональное;
  - С классом;
  - при желании выбери звонок-шаблон;
- время начала;
- время конца.

Нажми:

  Добавить

Если включена галочка:

  добавлять подряд

то после добавления занятия страница очистит название и автоматически сдвинет время на длительность добавленного занятия.

Это удобно, когда нужно быстро вставить несколько уроков подряд.

---

### Быстрый выбор дня

В каждой колонке дня есть кнопка:

  +

Она выбирает этот день в форме добавления занятия и прокручивает страницу к форме.

---

### Дублирование занятия

В таблице "Все занятия" у каждого занятия есть действия:

- Изменить;
- Дублировать;
- Удалить.

Кнопка "Дублировать" копирует занятие в форму добавления.

Это удобно, когда нужно создать похожий урок с тем же днём, типом и временем.

---

## Цвета типов занятий

По умолчанию:

- Персональное — зелёный цвет;
- С классом — синий цвет;
- конфликт — красный фон и красная рамка.

Цвета можно поменять в CSS в блоках:

  .lesson.type-personal {
    background: #f2fff6;
    border-left-color: #22a55a;
  }

  .lesson.type-class {
    background: #f2f7ff;
    border-left-color: #2f6fdb;
  }

## Как определяются конфликты

Конфликт определяется так:

- занятия происходят в один и тот же день недели;
- интервалы времени пересекаются.

Пример конфликта:

  Понедельник 08:30–09:15
  Понедельник 09:00–09:40

Такие занятия будут подсвечены красным.

Если занятие заканчивается ровно в момент начала другого, конфликтом это не считается.

Пример без конфликта:

  Понедельник 08:30–09:15
  Понедельник 09:15–10:00

## Где хранятся данные

Данные хранятся в браузере через localStorage.

Это значит:

- данные сохраняются после закрытия страницы;
- данные сохраняются после F5;
- данные не отправляются на сервер;
- данные не синхронизируются между разными браузерами или устройствами;
- если очистить данные браузера, данные могут пропасть.

Поэтому для важных изменений нужно делать выгрузку конфига.

## Экспорт конфига

На странице есть кнопки:

  Выгрузить конфиг (.js + .json)
  Только .js
  Только .json

Основная кнопка:

  Выгрузить конфиг (.js + .json)

скачивает два файла:

  schedule-config.js
  schedule-config.json

### Зачем два файла?

schedule-config.js нужен для автоподхвата страницей.

Его нужно положить рядом с schedule.html.

schedule-config.json нужен для:

- резервной копии;
- ручного просмотра;
- ручного редактирования;
- переноса данных;
- загрузки через кнопку "Загрузить конфиг".

Если браузер заблокировал одновременную загрузку двух файлов, используй кнопки:

  Только .js
  Только .json

---

## Автоподхват конфига при открытии

Если рядом с schedule.html лежит файл:

  schedule-config.js

страница читает его при открытии.

Внутри файла должно быть:

  window.SCHEDULE_CONFIG = {
    "version": 1,
    "exportedAt": "2026-10-13T18:00:00.000Z",
    "bells": [],
    "lessons": []
  };

### Как обновить расписание через файл

1. Открой страницу.
2. Внеси изменения или убедись, что текущее расписание правильное.
3. Нажми:

     Выгрузить конфиг (.js + .json)

4. Возьми скачанный:

     schedule-config.js

5. Положи его рядом с schedule.html, заменив старый файл.
6. Обнови страницу через F5.

---

## Как страница понимает, что файл изменился

При загрузке страница сохраняет в браузере признак внешнего конфига.

Если содержимое schedule-config.js отличается от того, что страница видела ранее, данные из файла заменят текущие данные в браузере.

Если файл не изменился, страница может оставить локальные правки в браузере.

Это сделано для сценария:

1. открыл страницу;
2. быстро внёс правки;
3. правки не потерялись после F5.

---

## Если заменил файл, а изменения не применились

Возможные причины:

### 1. Файл называется неправильно

Нужно, чтобы файл назывался строго:

  schedule-config.js

### 2. Файл лежит не рядом с schedule.html

Правильно:

  папка/
  ├── schedule.html
  └── schedule-config.js

### 3. Файл не изменился по содержимому

Если содержимое файла такое же, как уже сохранённая версия, страница может оставить локальные данные.

Решение:

- измени exportedAt вручную;
- или выгрузи конфиг заново кнопкой экспорта;
- или используй кнопку "Загрузить конфиг";
- или очисти данные сайта в браузере.

### 4. В файле синтаксическая ошибка

Если в schedule-config.js ошибка, страница не сможет его прочитать.

Проверь консоль браузера через F12.

## Импорт конфига

Кнопка:

  Загрузить конфиг

позволяет загрузить:

- .json;
- .js.

При загрузке конфиг полностью заменяет текущие занятия и звонки.

Перед заменой страница спросит подтверждение.

---

## Формат конфига

Конфиг имеет вид:

  {
    "version": 1,
    "exportedAt": "2026-10-13T18:00:00.000Z",
    "bells": [],
    "lessons": []
  }

### Поля звонка

  {
    "id": "bell-1",
    "name": "1 урок",
    "start": "08:30",
    "end": "09:15"
  }

Поля:

  Поле   Тип       Описание
  id     string    уникальный идентификатор
  name   string    название звонка
  start  string    время начала, ЧЧ:ММ
  end    string    время конца, ЧЧ:ММ

Звонки используются только как шаблоны времени при добавлении занятия.

На проверку конфликтов влияют только фактические время начала и конца занятия.

---

### Поля занятия

  {
    "id": "lesson-1",
    "title": "Математика",
    "day": 1,
    "type": "class",
    "start": "08:30",
    "end": "09:15"
  }

Поля:

  Поле   Тип       Описание
  id     string    уникальный идентификатор
  title  string    название занятия
  day    number    день недели от 1 до 7
  type   string    тип занятия: personal или class
  start  string    время начала, ЧЧ:ММ
  end    string    время конца, ЧЧ:ММ

## Ограничения

Текущая версия рассчитана на повторяющееся недельное расписание.

То есть занятия привязаны к дням недели и повторяются каждую неделю.

Пока не поддерживаются:

- конкретные даты;
- исключения по датам;
- каникулы;
- чётные и нечётные недели;
- кабинеты;
- учителя;
- классы как отдельные сущности;
- автоматическая проверка занятости кабинета или учителя.

Если нужно учитывать не только пересечение по времени, а, например, кабинет, учителя или класс, нужно добавлять новые поля и менять правило проверки конфликтов.

## Важные замечания

### Файл schedule-config.json автоматически не подтягивается

Для автоподхвата нужен именно:

  schedule-config.js

Файл:

  schedule-config.json

используется для резервной копии и импорта.

---

### Браузер и локальные файлы

Если страница открыта двойным кликом, браузер использует адрес вида:

  file:///...

В таком режиме браузеры часто запрещают читать соседние .json файлы через fetch.

Поэтому автозагрузка сделана через schedule-config.js, а не через schedule-config.json.

---

### Очистка данных браузера

Если очистить данные сайта или данные браузера, расписание может удалиться.

Поэтому после важных изменений нужно выгружать:

  schedule-config.js
  schedule-config.json

---

### Разные браузеры и устройства

Данные в localStorage не переносятся автоматически между:

- разными браузерами;
- разными профилями браузера;
- разными компьютерами;
- разными телефонами.

Для переноса используй выгрузку и загрузку конфига.

## Частые проблемы

### Страница не видит файл конфига

Проверь:

1. Файл называется именно:

     schedule-config.js

2. Файл лежит в той же папке, что и:

     schedule.html

3. Внутри файла есть строка:

     window.SCHEDULE_CONFIG = { ... };

4. В файле нет синтаксических ошибок.

---

### После замены файла данные не обновились

Варианты решения:

1. Нажать F5.
2. Проверить, что файл действительно заменился.
3. Открыть консоль браузера через F12 и посмотреть ошибки.
4. Изменить exportedAt в файле.
5. Загрузить конфиг через кнопку:

     Загрузить конфиг

---

### Браузер не скачивает два файла сразу

Некоторые браузеры могут блокировать автоматическую загрузку нескольких файлов.

В этом случае используй кнопки:

  Только .js
  Только .json

---

### В консоли ошибка 404 для schedule-config.js

Это значит, что файла нет рядом с schedule.html.

Не страшно, если ты работаешь только с данными в браузере.

Если нужен автоподхват конфига — создай или положи файл рядом.
